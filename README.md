# 🚀 Day 1: From Prompt to Action (Google ADK)

## 📌 High-Level Summary
This project explores the core concept of **AI Agents** using the Google Agent Development Kit (ADK). Unlike a standard Large Language Model (LLM) that simply generates text based on a prompt, an **AI Agent** can reason, take actions (like using tools), observe the results, and then formulate a final answer.
